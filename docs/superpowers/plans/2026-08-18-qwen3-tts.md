# Qwen3-TTS CustomVoice Gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` to the existing GPU4 LLM gateway as an authenticated OpenAI-compatible `/v1/audio/speech` API and Open WebUI model, supporting preset `voice` plus `instructions` only.

**Architecture:** LiteLLM keeps the existing virtual-key authentication boundary and forwards speech requests to model_manager. model_manager treats TTS as a first-class model type, validates speech input before allocating a GPU slot, cold-starts a dedicated pinned vLLM-Omni runtime on the selected slot, streams the binary audio response unchanged, and releases the slot through the existing idle-unload lifecycle. Chat and TTS remain mutually exclusive within each single-GPU slot.

**Tech Stack:** Python 3.12, aiohttp, LiteLLM 1.86.2, vLLM-Omni 0.26.0, Qwen3-TTS CustomVoice, Bash, systemd user services, unittest.
